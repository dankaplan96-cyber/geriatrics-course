# לטיפה ופאבלו: מבצע בית הפוך

משחק תלת־ממד לטלפון (three.js + Rapier). פותחים את `index.html` בדפדפן — אין צורך בהתקנה.

## מבנה
- `src/style.css` — עיצוב ה־UI וה־HUD
- `src/body.html` — מסכים, HUD ושליטה
- `src/engine.js` — עזרי רינדור, טקסטורות פרוצדורליות, פיזיקה, קלט, שמירה, רנדרר ומצלמה
- `src/world.js` — החדרים, הריהוט והקישוט
- `src/actors.js` — החתולים, החפצים השבירים, האפקטים והסכנות
- `src/game.js` — אודיו, UI, משימות ולולאת המשחק
- `original.html` — הגרסה הקודמת, להשוואה

אחרי שינוי בקבצי `src/` מריצים `node build.mjs`, שבונה מחדש את `index.html` כקובץ אחד.

לבדיקת ביצועים מוסיפים `?debug` לכתובת.
