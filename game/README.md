# בופי מן

משחק RPG בעברית בקובץ HTML אחד: משרד בבוקר, ציור בערב.

## לשחק
פותחים את `index.html` בדפדפן. אין צורך בהתקנה או בשרת.

## להתקין כאפליקציה (PWA)
כשהתיקייה הזאת מוגשת מאתר אמיתי (למשל GitHub Pages), המשחק ניתן להתקנה במסך הבית ועובד גם בלי אינטרנט:
`index.html`, `manifest.webmanifest`, `sw.js` והאייקונים צריכים לשבת יחד באותה תיקייה.

## שליטה
- מגע: הקשה כדי ללכת, החזקה כדי לנוע, הקשה על דמויות כדי לדבר.
- מקלדת: חיצים או WASD, Z/Enter לפעולה, X לחזרה, Shift לריצה, Esc לתפריט.
- בקר (Xbox / PlayStation / Switch): A פעולה, B חזרה וריצה, Y קרב אוטומטי, Start תפריט.
