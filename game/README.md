# המשמרת — מסע קליני בגריאטריה

משחק RPG בסגנון GBA / Gen‑3, שנבנה על המבנה והשפה הגרפית של **בופי מן RPG** (מסך נוף, HUD עליון, תיבת משימה זהובה, קרבות עם לוחיות וגריד פקודות, חלונות בסגנון v57, פתיח Mae Studio), עם כל התוכן הקליני של Clinical Mastery v2.1.

## איך מריצים

- מקומית: `npx http-server game` (או כל שרת סטטי) ופתיחת `index.html`.
- GitHub Pages: מגישים את התיקייה `game/` — הכל סטטי, בלי build.
- PWA: `manifest.webmanifest` + `sw.js` (עובד אופליין אחרי טעינה ראשונה). לכל גרסה מעדכנים את `VERSION` ב-`sw.js`.

## מהלך המשחק

| במשחק | המשמעות הקלינית |
|---|---|
| משמרת לילה במחלקה: חדר צוות, מסדרון, 4 חדרי מטופלים, מעבדה, חדר ישיבות | 7 מטופלים מתמשכים (לאה, רות, יוסף, אברהם, מרים, שרה, דוד) |
| ❗ מעל מיטה → קרב | אירוע קליני (58 אירועים) — "האויב" הוא הבעיה הקלינית |
| 🔍 אומדן (עולה ⏱ זמן) | Noticing — ★ ממצא קריטי · ◆ תומך · · רעש |
| 🧠 החלטה ב-4 שלבים | פרשנות → מטרה → התערבות → הערכה חוזרת |
| בחירת ביטחון לפני תשובה | כיול: "בטוח/ה" פוגע חזק כשצודקים ועולה יותר כשטועים |
| יציבות המטופל = HP | טעות מחמירה את המטופל; 0 = קוד (מקבלים סיכום מלא ומנסים שוב) |
| סיכום אחרי כל אירוע | ארבע ההחלטות, ממצאים קריטיים, פנינה, סיכון, מסירת SBAR |
| 7 ביקורים גדולים (Gym leaders) | 60% מאירועי הפרק פותחים את חדר הישיבות; תג פותח את הפרק הבא |
| טל במעבדה | 12 סבבי מעבדה קריטיים + **מעבדון**: 78 בדיקות "לתפוס" בחידון זיהוי |
| מתמחים במסדרון / ביפר 📟 | חזרה מרווחת על אירועים שכבר נפתרו |
| שולה בקפיטריה | חנות: ☕ זמן · 🔦 חשיפת ממצאים · 📘 הסרת 2 מסיחים · 🛡️ בדיקה כפולה · 🤝 יציבות |
| ספה בחדר הצוות | סיום משמרת, משימות משמרת חדשות, רצף ימים 🔥 |
| מדף הספרים | פותח את גרסת הלימוד המלאה (`library/`) |

שליטה: חיצים/WASD · Shift ריצה · Z/רווח/Enter פעולה · X/Esc חזרה · M תפריט. במגע: הקשה על משבצת = הליכה אליה (ואם זו מיטה או אדם — גם פנייה), החזקה = היגוי. בטלפון במצב אנכי המשחק מסתובב לרוחב, כמו בבופי מן.

נגישות: מהירות טקסט (כולל מיידי), גודל טקסט, ניגודיות גבוהה, הפחתת אפקטים (וגם `prefers-reduced-motion`), אזור `aria-live` לטקסט, ניווט מלא במקלדת.

## קבצים

```
game/
  index.html          מעטפת (HUD, מסך, תיבת הודעות, חלונות, פתיח)
  css/game.css        שפת הממשק של בופי מן v43–v57 + Mae splash
  js/content.js       התוכן הקליני (נוצר אוטומטית — לא לערוך ידנית)
  js/engine.js        קנבס 480×320 לוגי, טקסט RTL, קלט, סאונד ומוזיקה מסונתזים, אפקטים
  js/data.js          פרקים ותגים, סוגים קליניים, פריטים, מפות, דמויות
  js/art.js           כל הגרפיקה מצוירת בקוד: אריחים, ריהוט, דמויות, מטופלים, יצורים, רקעים
  js/ui.js            HUD, תיבת דיאלוג/פקודות, חלונות, טוסטים
  js/battle.js        קרבות: אירוע, ביקור גדול, סבב מעבדה, ביפר/מתמחה
  js/world.js         המחלקה: תנועה, NPC, שדה ראייה של מתמחים, ביפר, הליכה בהקשה
  js/main.js          מצב, שמירה, התקדמות, דיאלוגים, תפריטים, פתיח, לולאה
  js/mae.js           פתיח Mae Studio (מתוך בופי מן)
  library/            Clinical Mastery v2.1 המקורי (ספריית ידע)
tools/extract-content.js   מחלץ מחדש את התוכן מ-library/index.html
```

עדכון תוכן: עורכים את הגרסה המלאה ב-`game/library/index.html` ומריצים `node tools/extract-content.js` — הסקריפט גם בודק שכל מפתח תשובה תקין.

> כלי למידה בלבד. אינו מחליף טווחי מעבדה מקומיים, פרוטוקול מוסדי או שיקול דעת קליני בזמן אמת.
